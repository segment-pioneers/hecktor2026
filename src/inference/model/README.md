# Model Weights

This directory contains the trained model weights required by the inference pipeline.

The following models are required:

- Segmentation
  - `seg_fold1.pth`
  - `seg_fold2.pth`
  - `seg_fold3.pth`
  - `seg_fold4.pth`
  - `seg_fold5.pth`

- TN Staging
  - `t_stage_fold1.cbm`
  - ...
  - `t_stage_fold5.cbm`
  - `n_stage_fold1.cbm`
  - ...
  - `n_stage_fold5.cbm`

- Recurrence-Free Survival Prediction
  - `rfs_fold1.pkl`
  - ...
  - `rfs_fold5.pkl`
