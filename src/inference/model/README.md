# Model Weights

This directory contains the trained model weights required by the inference pipeline.

The following models are required:

- Segmentation
  - `seg_fold1.pt`
  - `seg_fold2.pt`
  - `seg_fold3.pt`
  - `seg_fold4.pt`
  - `seg_fold5.pt`

- TN Staging
  - `best_t_model_fold1.cbm`
  - ...
  - `best_t_model_fold5.cbm`
  - `best_n_model_fold1.cbm`
  - ...
  - `best_n_model_fold5.cbm`

- Recurrence-Free Survival Prediction
  - `survival_fold1.pkl`
  - ...
  - `survival_fold5.pkl`
